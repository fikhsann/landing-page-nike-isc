# 👟 Landing Page Nike (Clone Project)

Landing Page ini adalah hasil *rebuild* desain official Nike untuk keperluan latihan dan portofolio. Dibuat ulang dengan HTML, CSS (Tailwind), dan JavaScript, halaman ini meniru tampilan modern dan interaktif dari situs Nike.

## 🎯 Tujuan Proyek

- Melatih kemampuan frontend dengan meniru desain nyata.
- Menampilkan kemampuan layout, responsive design, dan animasi.
- Membangun portofolio UI/UX berkualitas tinggi.

## ✨ Fitur

- Hero section dengan headline dan gambar sepatu
- Navigasi sticky yang responsif
- Produk-produk unggulan
- Section promo/collection
- Tombol CTA (Buy Now / Shop)

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS
- JavaScript (DOM & interaksi dasar)
